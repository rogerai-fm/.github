# Security policy

This policy covers every public RogerAI repository that does not have its own.

## Reporting a vulnerability

Please report security issues privately. Do not open a public issue or pull request.

- Preferred: GitHub private vulnerability reporting (the repository's **Security** tab, then
  **Report a vulnerability**).
- Or email **security@rogerai.fm**.

We aim to reply within 72 hours. Include steps to reproduce and the impact. We will work out
a fix and a disclosure timeline with you.

Vulnerabilities in third-party dependencies should also be reported upstream.
